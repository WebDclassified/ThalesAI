# UI System

Theme: clean light enterprise SaaS.

Colors:
background #F6F8FB
surface #FFFFFF
text #172033
muted #68758A
border #E3E8F0
primary #635BFF
success #17A673
info #2F80ED
warning #C47C00
danger #D9485F

Typography:
Inter/system sans. H1 34–40px 700. Body 13–15px. Metadata 11–12px.

Geometry:
8px spacing scale. Cards 14–18px. Controls 9–10px.

UX rules:
- no gradients
- no overlapping elements
- visible focus states
- keyboard navigable controls
- responsive tables with horizontal containment, not page overflow
- loading/skeleton states
- empty/error states
- destructive actions require confirmation
- progress states must survive refresh
