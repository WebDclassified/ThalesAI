# Definition of Done

The MVP is done when:
- the default demo starts without paid services;
- user-created tasks persist locally;
- the AI API can be swapped by environment variables;
- AI failures degrade to fallback instead of breaking the run;
- the full workflow executes end-to-end;
- validation and deduplication are real code paths;
- source evidence is retained on records;
- dataset search/navigation is usable;
- analytics use computed dataset values;
- report generation works without AI;
- CSV and JSON export work;
- no secrets reach the browser;
- edge-case behavior is documented and tested;
- README and credits are present.
