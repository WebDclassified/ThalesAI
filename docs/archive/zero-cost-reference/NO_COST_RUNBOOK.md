# No-Cost Runbook

1. Install Node.js 22+ and Git.
2. Open the generated project.
3. Copy `.env.example` to `.env.local`.
4. Set `DEMO_MODE=true`.
5. Do not add paid API keys.
6. Install dependencies.
7. Initialize SQLite.
8. Seed deterministic demo data.
9. Run the dev server.
10. Follow the complete task journey.

Optional local AI:
- install Ollama
- pull qwen3:4b
- set OLLAMA_ENABLED=true

If AI is slow or unavailable, keep OLLAMA_ENABLED=false; the full demo still works.
