# Product Workflow

1. User describes a requirement.
2. System extracts intent and constraints.
3. System creates ResearchPlan.
4. User reviews plan.
5. System selects enabled source adapters.
6. Candidate records are collected.
7. Fields are extracted into schema.
8. Values are normalized.
9. Duplicates are detected/merged/reviewed.
10. Evidence is attached.
11. Records are validated.
12. Exceptions enter review queue.
13. Valid records become dataset.
14. Analytics are calculated.
15. Report is generated from the dataset.
16. User exports data.
17. Task/run history is retained.
