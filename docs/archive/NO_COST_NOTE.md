# Cost Boundary

The default hackathon demo does not require a paid service.

Required locally:
- Node.js
- the repository

Optional:
- your own OpenAI-compatible AI API key/endpoint

The deterministic demo source adapter and local file persistence are included so the workflow can still be demonstrated when external services are unavailable.

Your AI API itself may have a cost depending on the provider/plan; the project does not control that pricing.
