# Definition of Done

The MVP is complete only when a clean clone can run `DEMO_MODE=true` without paid credentials and a user can:
create a task → see AI-understood requirements → inspect a plan → run a collection → watch progress →
validate/deduplicate → review exceptions → open the dataset → inspect source evidence → view analytics →
generate a report → export CSV/JSON → reopen task history.

Security checks must pass. Core data-quality tests must pass. No secret can be committed. Demo data must be
clearly synthetic. Optional live adapters must not be required for the hackathon demo.
