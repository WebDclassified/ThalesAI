# Zero-Cost Strategy

## Required cost: $0
The default stack uses local software and synthetic data. No paid account is required.

| Layer | Choice | Cost |
|---|---|---|
| UI | Next.js + React + Tailwind | $0 software |
| Components | shadcn-style local components | $0 software |
| Database | SQLite | $0 software |
| ORM | Drizzle | $0 software |
| AI | Ollama + local open models | $0 API fees |
| Demo data | local JSON/SQLite seed | $0 |
| Search | Mock by default; optional local SearXNG/GDELT | $0 software/API requirement, subject to usage terms |
| Export | local CSV/JSON generation | $0 |
| Hosting | not required | $0 required spend |

## Important distinction
Free software does not mean zero electricity/hardware/network usage. Optional external services can
change terms, quotas or availability. The hackathon demo should therefore remain functional locally.
